# Descubra Piaçaguera — Conecta Caiçara

Guia digital de cicloturismo sustentável da comunidade caiçara de Piaçaguera (Paranaguá, PR), do projeto Rodas sobre Areia / Conecta Caiçara.

## Como rodar
Abra o `index.html` no navegador. Não precisa instalar nada.

## Estrutura
- `index.html` — páginas e seções
- `style.css` — estilos
- `script.js` — dados (trilha, artesanato, gastronomia, pontos, hospedagens) e lógica
- `assets/logo.jpeg` — logo do projeto
- `assets/fotos/` — coloque aqui as fotos (veja abaixo)

## Como editar os dados
Todos os dados ficam no começo do `script.js`. Cada item tem:
- `verificado: true` se a informação foi conferida (preencha `fonte`);
- `verificado: false` se ainda precisa de confirmação com o morador. O site mostra o aviso "em confirmação";
- `contato`: `'tel:+55DDDNUMERO'` ou `'https://wa.me/55DDDNUMERO'`. Sem contato, o botão não aparece;
- `imagem`: caminho da foto, por exemplo `'assets/fotos/igreja.jpg'`, e `alt` com a descrição da foto.

## Antes de publicar
- Confirmar com cada morador/comerciante a autorização para divulgar nome, telefone e foto.
- Usar apenas fotos próprias ou com autorização de quem fotografou.

## Fontes das informações verificadas
- Cartilha "O Retrato das Comunidades da Baía de Paranaguá" — Portos do Paraná (2021)
- Rede Caiçara de Turismo Comunitário — https://redecaicara.wordpress.com/
- Agência Estadual de Notícias e Governo do Paraná (Trilha Caiçara, turismo comunitário)
